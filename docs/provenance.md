### Documented deviation: font

The generator recommended **Noto Sans Thai** for a Nepal tourism product. That family has Thai script
coverage and **no Devanagari glyphs**, so Nepali text would fall back to a system font and render with
inconsistent metrics. Replaced with:

- **Mukta** — Devanagari + Latin, weights 300–700, Google Fonts rank 273, designed for Indian-language UI.
- **Noto Sans Devanagari** — fallback, Devanagari + Latin, weights 100–900.

Verified by querying the skill's own font database:

```bash
python3 .hermes/skills/ui-ux-pro-max/scripts/search.py \
  "nepali devanagari sans serif multilingual" --domain google-fonts
```

Both families appear in `data/google-fonts.csv` with `devanagari | latin | latin-ext` subsets.

### Documented deviation: motion

The generator's landing pattern is `Scroll-Triggered Storytelling` (parallax, scroll-scrubbed chapters).
The product mandate is "very simple UI, only required buttons, only required decorations", and the
generator's own anti-pattern is "Generic photos + Complex booking".

Decision: keep the pattern's **content order** (hook → problem → journey → solution → CTA) and drop the
scroll-driven motion. `--motion` is pinned to 2. No GSAP in v1. Any future reintroduction of scroll motion
must pass the skill's own caveats: disabled under `prefers-reduced-motion`, DOM reading order complete,
offscreen chapters paused, each chapter rendered in its final readable state.

### Contrast verification

All nine text/background pairs in the generated palette were measured against WCAG 2.1 relative luminance.
Every pair passes AA for normal text (≥ 4.5:1):

| Pair | Ratio |
|---|---|
| foreground `#0C4A6E` on card `#FFFFFF` | 9.46:1 |
| foreground `#0C4A6E` on background `#F0F9FF` | 8.87:1 |
| muted-foreground `#475569` on background `#F0F9FF` | 7.11:1 |
| muted-foreground `#475569` on muted `#E8F2F8` | 6.67:1 |
| on-primary `#0F172A` on primary `#0EA5E9` | 6.44:1 |
| on-accent `#000000` on accent `#EA580C` | 5.90:1 |
| `#0F172A` on accent `#EA580C` | 5.02:1 |
| on-destructive `#FFFFFF` on destructive `#DC2626` | 4.83:1 |

This check runs in CI as `tests/tokens.test.ts` so a future regeneration cannot silently break contrast.
